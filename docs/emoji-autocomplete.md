# Emoji shortcuts in floating search

Type `:wink`, `:heart`, `:thumbsup` or another emoji keyword in the floating picker's search field. A compact scrollable list shows an emoji and its matching keyword. Tap a row to replace that shortcut with Unicode emoji; text on either side stays intact and the keyboard remains open. Search mode, source and existing filters continue to apply. The keyboard's arrow keys and completion action work through Android autocomplete. Back dismisses suggestions before collapsing search.

The interaction was traced in Telegram Android at commit [`f32ffee`](https://github.com/DrKLO/Telegram/tree/f32ffeec763f0bdbf4bec25b52d654f77bff733d):

- [`MentionsAdapter.searchUsernameOrHashtag`](https://github.com/DrKLO/Telegram/blob/f32ffeec763f0bdbf4bec25b52d654f77bff733d/TMessagesProj/src/main/java/org/telegram/ui/Adapters/MentionsAdapter.java#L1180) scans backward from the cursor to find a colon and records its replacement range.
- [`MediaDataController.getEmojiSuggestions`](https://github.com/DrKLO/Telegram/blob/f32ffeec763f0bdbf4bec25b52d654f77bff733d/TMessagesProj/src/main/java/org/telegram/messenger/MediaDataController.java#L9115) looks up keyword prefixes on a storage worker, deduplicates emoji and returns results to the UI.
- [`MentionCell.setEmojiSuggestion`](https://github.com/DrKLO/Telegram/blob/f32ffeec763f0bdbf4bec25b52d654f77bff733d/TMessagesProj/src/main/java/org/telegram/ui/Cells/MentionCell.java#L184) renders emoji plus `: keyword`. [`MentionsContainerView`](https://github.com/DrKLO/Telegram/blob/f32ffeec763f0bdbf4bec25b52d654f77bff733d/TMessagesProj/src/main/java/org/telegram/ui/Components/MentionsContainerView.java#L653) commits only the recorded range.

`EmojiShortcode` adapts that cursor-token approach. SAO additionally rejects URLs, times and escaped colons, hides matches for a nonempty selection, and includes an unfinished suffix/optional closing colon when completing in the middle of a token. The offsets remain UTF-16 so existing supplementary characters and joined emoji do not shift the replacement range.

SAO hosts the interaction in the official `MaterialAutoCompleteTextView`, with a themed surface, 48 dp minimum suggestion rows and roughly 3½ visible rows. Android manages keyboard navigation, popup placement and the accessible selection window. Both ordinary completion and Material's accessibility completion replace just the current shortcut. Query/cursor snapshots reject stale results or obsolete row taps. Closing the picker cancels lookup work; no polling or persistent typing/usage history is added.

Telegram's dictionary is downloaded through its account-dependent emoji-keyword API. SAO instead bundles 1,870 standard emoji entries, combining pinned [gemoji aliases](https://github.com/github/gemoji/tree/fadaeaf1f1a9be82b321316a6c5502e43138b2f6) and [Unicode CLDR English keywords](https://github.com/unicode-org/cldr-json/tree/91c267402229a59e3ef2774544f001bf959e8809). Lookup is offline and independent of the media source or Telegram installation. Exact aliases rank first, followed by alias/keyword prefixes; variation-selector-equivalent emoji appear once. The current dictionary is English. Telegram's account-specific animated/custom emoji are not imported.

The immutable dictionary loads lazily on IO and builds/searches its prefix index on the existing CPU dispatcher. Latest-request cancellation and a second snapshot check guard UI updates. Only the dictionary remains in memory; suggestions and media search results are not stored in a new cache. The existing media-search debounce and query persistence remain unchanged. Accepting a suggestion passes the resulting Unicode text through SAO's existing search path, including Immich Context search.

Regenerate the small UTF-8 asset and bundled attribution with `python3 tools/generate_emoji_keywords.py`. Builds do not download emoji data. Source/license details are in [third-party notices](../THIRD_PARTY_NOTICES.md).

Validation: debug/prerelease builds, 30 JVM tests and lint (0 errors) pass. Android 15 emulator checks cover real row taps, preserved clipboard/keyboard state, cursor edits, unmatched shortcuts, Back/reopen, composing spans, joined emoji and hardware completion, plus existing search/filter restoration. Light/dark, 200% text and landscape screenshots were visually inspected using bundled samples and localhost fixtures. [Preview gallery](screenshots/README.md).
